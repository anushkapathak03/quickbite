# QuickBite – College Canteen Pre-Order & Pickup

Skip the queue. Order ahead. Grab & go.

A React + TypeScript + Vite progressive web app with three connected panels:
Student App, Kitchen POS and Admin Console.

## Features
- Menu search, cart, simulated UPI payment
- Kitchen accept/reject, live status board
- QR pickup verification
- Admin analytics and menu management

## Run locally
npm install
npm run dev
